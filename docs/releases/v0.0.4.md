# splice9000 0.0.4

**Adapters**: add-ons you choose to have. Find them in the
[adapter catalog](https://github.com/solacecasino/splice9000-adapters/blob/main/CATALOG.md),
drop the zip on the window, and remove anything you don't need, including
what comes with the app.

**Downloads:** macOS (universal), Windows (x64 and Arm) and Linux (x64 and
Arm). All of them need [ffmpeg](https://ffmpeg.org). Install steps are in
the [README](https://github.com/solacecasino/splice9000#installing).

## What's new

- **Install by dropping a zip.** Drop an adapter's zip (or folder) on the
  window, or use **Adapters → Install Adapter…**. splice9000 shows what it
  adds and what it may do, and installs it only when you click **Install**:
  Return does nothing and Escape cancels, so a stray key press can't install
  anything. Keys are paused while it asks.
- **Two adapters come built in, and both can be removed:**
  - **Export Presets:** YouTube 1080p, vertical 9:16, square, GIF, ProRes 422
    HQ, WebM and sound only. Pick one in the Export panel or under
    **File → Export As**. It's only presets: nothing of it runs.
  - **Frame Grab:** **File → Save Frame as PNG…** (⌘⇧G), the frame under the
    playhead at full size.

  **Remove** in the Adapters panel leaves a built-in adapter out completely
  (no menus, no keys, nothing runs), and **Add Back** returns it, offline.
  Removing an adapter you installed moves it to the Trash.
- **The Adapters panel** (Adapters → Manage Adapters): every adapter with
  what it adds, what it may do, its commands and panels, Remove, and
  Install.
- **The catalog**, in its own repo:
  [solacecasino/splice9000-adapters](https://github.com/solacecasino/splice9000-adapters).
  Its first adapter is **Scene Split** (Edit → Split at Scene Changes, ⌘⇧K),
  which cuts a clip wherever the picture changes scene, as one undo step.
  splice9000 never goes online; **Adapters → Browse Adapter Catalog** opens
  the page in your browser.
- **Make your own** in a few lines of Python with the catalog's `splice.py`
  and template, or with no code at all for export formats. Adapters can add
  commands to any menu with default keys, their own panels, and export
  formats; they can read the edit and change it as one undo step, and use
  splice9000's ffmpeg. The protocol is in
  [docs/adapters.md](https://github.com/solacecasino/splice9000/blob/main/docs/adapters.md).
- **Adapters menu**, and adapters' commands in File, Edit, View and
  Playback where they ask to be, with your shortcuts from keys.toml. keys.toml
  can bind adapters' commands and export formats too, and the menus now
  update when keys.toml changes.
- **Files named on the command line** open like dropped files (Open With on
  Windows and Linux).

## Tested

- In the app on this Mac: the install prompt for a dropped zip, installing
  from the keyboard, Scene Split cutting a three-scene clip at exactly 2.0
  and 4.0 s, and ⌘Z putting it back.
- By CI on every download: every built-in export format exported for real
  through ffmpeg with the right tracks and sizes; Frame Grab saving the
  right frame from inside the download; 38 unit tests, including adapters
  talking both ways, removing and adding back built-ins, installing zips
  and folders, refusing zips that try to write outside their folder, and
  refusing programs built for another computer.

Not tested by hand: clicking Remove and Add Back with a mouse (their logic
is unit-tested), and Python adapters on Windows (they need Python
installed, as with Folio's).

## Compatibility

Everything from 0.0.3 works as it is. New files appear only when you use
what they're for: `adapters/` and `approvals.json` when you install an
adapter, and `adapters.toml` when you remove a built-in one.
