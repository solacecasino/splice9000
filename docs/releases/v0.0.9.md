# splice9000 0.0.9

A small patch: on a Mac, splice9000 opens the video it's handed.

**Downloads:** macOS (universal), Windows (x64 and Arm) and Linux (x64 and
Arm). All of them need [ffmpeg](https://ffmpeg.org). Install steps are in
the [README](https://github.com/solacecasino/splice9000#installing).

## What's new

- **Videos and projects open from Finder, the Dock and the other 9000
  apps.** splice9000 used to start empty when macOS handed it a file (a
  double-click on a `.splice`, **Open With**, `open -a`, or leaf9000 or
  text9000 passing one on). Now a video is added and a `.splice` opens,
  just like a drop, and a file sent while splice9000 is running goes to
  its window. Windows and Linux already opened files named on the
  command line; nothing changes there.
- **`.splice` projects open in splice9000 by double-click** on a Mac, and
  videos list it under **Open With** without changing which app opens
  them.
- The whole 9000 series is now five apps: text9000 (writing), splice9000
(video), wave9000 (sound), grace9000 (photos) and the new
[leaf9000](https://github.com/solacecasino/leaf9000) (comics and books, the
reader Leaf renamed). Each one hands the others' files to them.

Tried on an Apple M2 with `open -a`: an MP4 with sound was added as a
clip, picture and sound.

## Compatibility

Everything from 0.0.8 works the same: projects, settings, keys, layouts
and adapters (splice9000 adapters 0.3.0).
