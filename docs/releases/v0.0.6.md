# splice9000 0.0.6

The catalog is easier to reach, and export formats can level the sound.

**Downloads:** macOS (universal), Windows (x64 and Arm) and Linux (x64 and
Arm). All of them need [ffmpeg](https://ffmpeg.org). Install steps are in
the [README](https://github.com/solacecasino/splice9000#installing).

## What's new

- **The catalog, one click away.** **Adapters** at the top right of the
  window opens the Adapters panel, which now starts with **Browse the
  adapter catalog** (and how to install: download a zip, drop it on the
  window). It's in the Help menu too, and goes straight to the catalog page.
- **Three adapters in the catalog**, released today as
  [splice9000 adapters 0.2.0](https://github.com/solacecasino/splice9000-adapters/releases/tag/v0.2.0):
  - **Silence Cut**: Edit → Remove Silences (⌘⇧J), jump cuts for talking
    video.
  - **Loudness Normalize**: export formats leveled to −14 LUFS (YouTube,
    Spotify), −16 LUFS (podcasts) or −23 LUFS (broadcast). It needs this
    version.
  - **Scene Split** 0.2.0: now in Rust, so it works on Windows without
    Python.
- **Export formats can filter the sound** (`audio_filter`), as they could
  the picture. This is what Loudness Normalize is made of.
- **Adapters can say which splice9000 they need** (`requires`). An older
  splice9000 refuses the adapter and says which version to get, instead of
  installing it and quietly leaving out what it doesn't understand.
- Adapter protocol 2. Adapters written for protocol 1 work as they are.

## Tested

- 41 unit tests, including the sound filter in an export and refusing an
  adapter that needs a newer splice9000.
- In this build on a Mac: all three adapters installed from their zips
  through the install prompt, one after the other; Silence Cut, run with
  ⌘⇧J, took the 1.3-second silence out of a talking clip. Each adapter is
  also tested on all six platforms in its own release.
- CI on every download, as before.

## Compatibility

Everything from 0.0.5 works as it is. splice9000 0.0.5 doesn't know
`requires` or `audio_filter`, so Loudness Normalize in 0.0.5 would export
without leveling; its catalog entry and description say it needs 0.0.6.
