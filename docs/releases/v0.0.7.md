# splice9000 0.0.7

Editing tools: waveforms, thumbnails, J/K/L, snapping and crossfades. Each
is an adapter, so you can remove any of them.

**Downloads:** macOS (universal), Windows (x64 and Arm) and Linux (x64 and
Arm). All of them need [ffmpeg](https://ffmpeg.org). Install steps are in
the [README](https://github.com/solacecasino/splice9000#installing).

## What's new

Five adapters come built in. Each is listed in the
[catalog](https://github.com/solacecasino/splice9000-adapters/blob/main/CATALOG.md)
(released as splice9000 adapters 0.3.0). Remove one in the Adapters panel
and nothing of it is left; **Add Back** returns it.

- **Waveforms:** each clip's sound drawn on the timeline. Each file is read
  once and the result is kept in the config folder's `cache`.
- **Thumbnails:** pictures from each clip along it, also kept. An hour of
  video takes seconds, because long files are read a keyframe at a time.
- **Shuttle:** J/K/L playback.
  - L plays forward, and each press goes faster: 2x, 4x, then 8x.
  - J does the same backward.
  - K stops.
  - Pressing the other way slows down first.
  - Faster than real time, the sound speeds up at the same pitch.
  - Backward shows pictures without sound.
- **Snapping:** while dragging, the playhead snaps to cuts, and a clip's
  end snaps to the playhead. Hold Alt (Option) to drag freely.
- **Crossfades:** blend picture and sound across a cut, from the Edit menu.
  - **Crossfade at Nearest Cut** (⌘D) and **Remove Crossfade** (⌘⇧D).
  - **Crossfade Every Cut** and **Remove All Crossfades**.
  - **Crossfade Length…**, which sets the length for new crossfades (0.5 s
    to start with).
  - The preview plays a crossfade just as it exports.
  - The fade is centered on the cut, so nothing on the timeline moves.
  - Where a clip has no footage past the cut, its last (or first) picture
    holds.

Adapter protocol 3 adds these:

| Addition | What it does |
|---|---|
| `playback.set` | Lets an adapter play, stop, or change the speed |
| `media.waveform` and `media.thumbnails` | Draw on clips |
| `media` event | Tells adapters when files are added |
| `fade` and `rate` in the edit | Crossfades, and the current playback speed |
| `[snapping]` in adapter.toml | Turns snapping on, with no program to run |

Adapters written for protocols 1 and 2 work as they are.

## Tested

- **Unit tests (45):**
  - Crossfade maths.
  - A real export with two crossfades: one with footage on both sides, and
    one where a picture has to hold. The length doesn't change.
  - Snapping and Alt, driven by pointer input fed through egui.
- **The five adapters' programs:** each is run the way splice9000 runs it,
  with real ffmpeg, on all six platforms.
- **In this build on a Mac:**
  - The five adapters, built from the catalog, came up preinstalled, and
    thumbnails and waveforms appeared on the clips.
  - Crossfades show as a cross on the timeline. The preview at a cut shows
    both clips blended. ⌘D added a second crossfade.
  - J/K/L: L played at 1x, L again at 2x, K stopped, and J went backward.
  - With Waveforms and Thumbnails removed, the clips were plain and neither
    program started.
- **CI on every download,** as before. It now also runs the editing
  adapters inside each download.

## Compatibility

- Projects from earlier versions open as they were.
- A project with crossfades still opens in 0.0.6, but it plays and exports
  there without them, as straight cuts.
- The new adapters say `requires = "0.0.7"`, so an older splice9000 refuses
  them and says which version is needed.
